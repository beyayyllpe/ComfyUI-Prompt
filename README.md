# ComfyUI-Prompt

> 面向中文用户的 ComfyUI 提示词工具集：用大模型把中文描述翻译 / 扩写成适合各类底模的提示词，支持多图逆推和图像编辑指令，零依赖、配置全在 JSON 里。

## 功能特色

**按底模架构输出，不用自己懂提示词格式**
选择你要用的底模类型，节点会输出最适合它的格式：中文自然语言（Z-Image / Qwen-Image）、英文句子（Krea 2 / FLUX）、英文标签（SDXL / Pony / Illustrious）。

**扩写程度可调**
从"只翻译不扩写"到"详细扩写"共四档，扩写时紧扣原意，把"优雅""电影感"这类抽象词转成具体的服装、光线、镜头描述。

**图像逆推 + 多图融合 + 编辑指令**
最多接入 10 张图片，接口随连线自动增加。可以逆推单张图的提示词，也可以"用图1的人物、图2的服装、图3的场景"融合成一段提示词，还能为 Qwen-Image-Edit、FLUX Kontext 等编辑模型生成精确的改图指令。

**多家服务商，配置全在 JSON**
内置 DeepSeek、通义千问、Gemini、OpenAI、Claude，以及腾讯、百度官方机器翻译。任何 OpenAI 兼容接口（硅基流动、智谱、Kimi、OpenRouter 等）都能在 JSON 里添加，下拉框自动出现，无需改代码。

**为国内用户设计**
国内服务商强制直连，不走代理、不耗机场流量；全中文界面，复杂参数有悬浮说明；推荐模型下线时自动切换可用模型。

**AI 指令完全可改**
所有系统指令都在 `ai_prompt_templates.json` 里，改完保存即生效，**无需重启 ComfyUI**。

**零依赖**
只使用 Python 标准库和 ComfyUI 自带的库，不需要 `pip install` 任何东西，不会和其他插件冲突。

**完整日志**
每次调用在命令行打印完整流程：服务商、模型、设置、耗时、token 用量、结果；出错时附带中文解决建议。

## 安装

### 方式一：Git 克隆（推荐）

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/beyayyllpe/ComfyUI-Prompt.git
```

### 方式二：手动下载

在本页点击 **Code → Download ZIP**，解压后把文件夹放到 `ComfyUI/custom_nodes/` 下，文件夹名改为 `ComfyUI-Prompt`。

> 注意：解压后常会多套一层文件夹。正确的结构是 `custom_nodes/ComfyUI-Prompt/__init__.py`，而不是 `custom_nodes/ComfyUI-Prompt/ComfyUI-Prompt/__init__.py`。

### 安装后

重启 ComfyUI，启动日志里出现以下内容即表示加载成功：

```
[CustomNodes] ✓ ai_translator.py
[CustomNodes] ✓ prompt_list.py
[CustomNodes] 提示词翻译 | 已配置：无 | 未填Key：DeepSeek、通义千问、Gemini……
```

首次启动会在插件目录自动生成两个文件：`ai_prompt_keys.json`（填 Key）和 `ai_prompt_templates.json`（AI 指令模板）。

### 环境要求

- ComfyUI 较新版本（建议 2026 年以后的版本）
- 无需额外 Python 依赖
- 使用 Gemini / OpenAI / Claude 等海外服务需要能访问外网

## 配置 API Key

用记事本（推荐 VS Code 或 Notepad++）打开插件目录下的 `ai_prompt_keys.json`，把 Key 填进对应位置：

```json
{
  "DeepSeek": "sk-xxxxxxxx",
  "通义千问": "",
  "Gemini": "AIzaSy-xxxxxxxx",
  "OpenAI": "",
  "Claude": "",
  "腾讯翻译_SecretId": "",
  "腾讯翻译_SecretKey": "",
  "百度翻译_APPID": "",
  "百度翻译_密钥": "",
  "自定义服务商": { }
}
```

用不到的留空即可。保存后**重启 ComfyUI**。

Key 的读取顺序：节点上的"API密钥"参数 → `ai_prompt_keys.json` → 系统环境变量（`DEEPSEEK_API_KEY`、`DASHSCOPE_API_KEY`、`GEMINI_API_KEY`、`OPENAI_API_KEY`、`ANTHROPIC_API_KEY` 等）。

> ⚠️ **不要把 Key 填在节点上。** ComfyUI 会把整个工作流写进出图 PNG 的元数据，分享图片就等于分享了你的 Key。节点上的"API密钥"只适合临时测试，也不会自动保存。

这两个是**机器翻译**，只能把中文翻译成英文，不能扩写，适合需要稳定、低成本翻译的场景。各有大额免费额度（以官网为准）。

|         | 腾讯翻译                               | 百度翻译                     |

| 凭据位置    | 访问管理 → API 密钥管理                    | 开发者信息                    |

## 使用说明：提示词翻译

### 常显参数

| 参数        | 作用                                    |
| --------- | ------------------------------------- |
| 文本        | 输入描述或编辑意图，可用"图1""图2"引用接入的图片。只接一张图时可留空 |
| 目标格式      | 按你要用的底模选择，见下表                         |
| 扩写程度      | 不扩写 / 简洁 / 适中 / 详细                    |
| 服务商       | 下拉框内容来自 `ai_prompt_keys.json`         |
| 🔄 获取模型列表 | 查询当前 Key 可用的模型，弹出可搜索的列表               |
| 模型        | 留空 = 推荐模型                             |
| 创意度       | 扩写的发散程度，建议 0.5~0.8。翻译、看图、编辑模式会自动使用低数值 |
| 每次运行      | 固定：内容不变时复用上次结果，不重复扣费；随机：每次重新生成        |


### 目标格式

| 选项               | 适用底模                         | 输出           |
| ---------------- | ---------------------------- | ------------ |
| 中文（Qwen/ZIT/通用）  | Z-Image、Qwen-Image、可图、混元、Wan | 中文自然语言       |
| 英文句子（Krea2/FLUX） | Krea 2、FLUX.2                | 英文自然语言句子     |
| 英文标签（SDXL/Pony）  | SDXL、Pony、Illustrious        | 英文逗号标签       |
| 编辑指令（英文）         | Qwen-Image-Edit、FLUX Kontext | 英文改图指令       |
| 编辑指令（中文）         | Qwen-Image-Edit              | 中文改图指令       |
| 负面词（英文）          | 所有（仅 CFG > 1 时有效）            | 英文负面提示词      |
| 不处理              | —                            | 原样输出，不调用 API |

> ⚠️ SDXL 系列的 CLIP 文本编码器**看不懂中文**，给 SDXL 用一定要选"英文标签"。

### 扩写程度

| 档位  | 文生文              | 看图 / 编辑             |
| --- | ---------------- | ------------------- |
| 不扩写 | 只翻译整理，不增加内容      | 只写最核心的信息            |
| 简洁  | 补关键细节，约 40~60 字  | 写主要特征               |
| 适中  | 补完整细节，约 80~120 字 | 覆盖全部检查项             |
| 详细  | 丰富细节，约 150~220 字 | 逐项展开，材质、纹样、光线层次都写清楚 |

看图和编辑模式下，扩写程度控制的是**描述有多细**，不会脑补图片里没有的内容。

### 图像输入（最多 10 张）

新建节点时只有"图像1"，接上后自动出现"图像2"，依次增加到最多 10 个；断开后多余的空接口会自动收回。发给 AI 时每张图标注为"图N"，**编号与输入口一致**（只接了图像1 和图像3，AI 看到的就是图1、图3）。

**三种用法：**

**单图逆推**：接图像1，文本留空，目标格式按底模选。

**多图融合**：接多张图，文本写"用图1的人物，穿图2的服装，放在图3的场景里"，输出一段统一画面的提示词。未指定分工时以图1为主体。

**编辑指令**：目标格式选"编辑指令"，文本写意图，例如"让图2的女孩穿上图1的衣服"。输出会具体描述要迁移的元素，并写明需要保持不变的部分。

> 看图需要服务商支持视觉能力。DeepSeek 不支持，选错会在调用前直接提示，不浪费额度。
> Qwen-Image-Edit 本身最多接 3 张图，编辑指令中提到的图应与编辑模型实际接入的图一致。
> 每张图大约消耗 1000 token 左右，图越多费用越高。

### 高级参数（点"显示高级输入"展开）

| 参数       | 作用                                          |
| -------- | ------------------------------------------- |
| 思考模式     | 让 AI 先推理再回答。复杂要求更不易遗漏，但更慢更贵，平时建议关闭          |
| 风格方向     | 给画面定调，如"胶片摄影""日系清新""赛博朋克"                   |
| 开头固定文字   | 不经过 AI，原样放在最前面，适合 LoRA 触发词、`<sks>`          |
| 结尾固定文字   | 不经过 AI，原样放在最后面                              |
| 给AI的额外要求 | 追加规则，如"人物是亚洲面孔""不要出现文字"                     |
| API密钥    | 临时填写 Key（不推荐，见上文）                           |
| 代理地址     | 海外服务商使用的本地代理端口，如 `127.0.0.1:7890`。留空则使用系统代理 |
| 自定义指令    | 完全替换本次的系统指令，临时试验用                           |
| 详细日志     | 额外打印系统指令全文、请求参数、API 原始返回                    |

## 使用说明：多行提示词

一个文本框每行写一条提示词，点一次运行，下游节点依次执行，写几行就出几张图。最初为 Qwen-Image-Edit-2511 多角度 LoRA 制作训练集而设计。

| 参数 | 作用 |
|---|---|
| 提示词 | 一行一条。空行和 `#` 开头的行会被忽略 |
| 开头补充 | 自动加在每行开头，默认 `<sks>`，已存在则不重复添加 |
| 结尾补充 | 自动加在每行末尾 |
| 从第几条开始 | 只重跑部分时使用 |
| 最多跑几条 | 0 = 全部 |
| 保存子文件夹 | 图片保存到 `output/该文件夹` |

**输出**：提示词列表（接提示词节点）、文件名列表（接"保存图像"的文件名前缀，文件名会带编号和角度）、条数。

**中文角度简写自动转英文：**

| 类别  | 简写 → 英文                                                                           |
| --- | --------------------------------------------------------------------------------- |
| 方位  | 正面 / 右前 / 右侧 / 右后 / 背面 / 左后 / 左侧 / 左前 → front view / front-right quarter view / … |
| 俯仰  | 仰拍 / 平视 / 微俯 / 俯拍 → low-angle / eye-level / elevated / high-angle shot            |
| 景别  | 特写 / 中景 / 远景 → close-up / medium shot / wide shot                                 |

```
背面 平视 中景
右前 仰拍 特写
right side view high-angle shot close-up
# 这是注释
```

## 自定义服务商

任何兼容 OpenAI 格式的接口都可以添加。在 `ai_prompt_keys.json` 的 `自定义服务商` 中加入：

```json
"自定义服务商": {
  "硅基流动": {
    "base": "https://api.siliconflow.cn/v1",
    "model": "Qwen/Qwen2.5-72B-Instruct",
    "key": "sk-xxx",
    "domestic": true,
    "vision": false
  },
  "OpenRouter": {
    "base": "https://openrouter.ai/api/v1",
    "model": "google/gemini-3.8-flash",
    "key": "sk-or-xxx",
    "domestic": false,
    "vision": true
  }
}
```

| 字段       | 说明                                             |
| -------- | ---------------------------------------------- |
| base     | 接口地址，**必填**，以 `/v1` 结尾，不要带 `/chat/completions` |
| model    | 默认模型名                                          |
| key      | API Key                                        |
| domestic | `true`：国内服务，直连不走代理；`false`：走代理                 |
| vision   | `true`：该模型能看图；`false`：接图时会提示不支持                |

保存后**重启 ComfyUI**，下拉框即出现新服务商。名字以"示例"开头或 `base` 为空的条目会被自动跳过。

**关于 domestic**：它只控制程序层面是否使用系统代理 / 代理地址。如果你使用路由器上的 OpenClash 或 Clash 的 TUN 模式等透明代理，流量走向由代理规则决定，此字段基本不起作用，也不会冲突。

**关于 vision**：内置服务商也可以覆盖默认值。例如将来 DeepSeek 支持看图了，把它改成字典形式即可，无需更新插件：

```json
"DeepSeek": { "key": "sk-xxx", "vision": true }
```

**只修改 Key 或模型名不需要重启**；新增或删除服务商需要重启。

## 修改 AI 指令模板

所有系统指令都在 `ai_prompt_templates.json` 中，**改完保存，下次运行立即生效，无需重启**。

| 模板 | 用于 |
|---|---|
| 硬性规则 | 所有模式通用的规则 |
| 扩写核心 | 扩写时的主要指令 |
| 篇幅_简洁 / 适中 / 详细 | 扩写字数 |
| 输出_中文 / 英文句子 / 英文标签 | 各格式的输出要求 |
| JSON格式要求 | 英文扩写时要求返回中英双语 |
| 不扩写_中文 / 英文句子 / 英文标签 | 只翻译整理 |
| 负面词 | 负面词模式 |
| 图像_中文 / 英文句子 / 英文标签 / 负面词 | 看图模式 |
| 图像详细度_* | 看图时的详细程度 |
| 多图融合 | 多张图时的组合规则 |
| 编辑_英文 / 编辑_中文 | 编辑指令模式 |
| 编辑详细度_* | 编辑指令的详细程度 |
| 随机提示 | "每次运行=随机"时追加 |
| 英文重试强化 | 英文模式返回中文时，重试追加的强化要求 |

**注意事项：**

- 保持 JSON 格式正确：换行写成 `\n`，引号写成 `\"`
- 文件改坏或删除时，自动使用内置默认值，不会报错
- 删除某一条后重启，会自动补回该条的默认值
- 英文模式的指令建议保留 "Output English only"，减少返回中文导致的重试
- 更新插件不会覆盖你修改过的模板

临时试验某种写法时，可以用节点高级参数里的"自定义指令"，试好了再写进模板文件。

每次调用都会在 ComfyUI 命令行打印完整流程：

```
[提示词翻译 14:23:05] ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  服务商：Gemini  模型：gemini-3.8-flash（推荐）
  模式：英文标签（SDXL/Pony）  扩写：详细  创意度：0.20
  思考模式：关闭  运行方式：固定
  识图：2 张（图1 1200×1200→1024×1024，图2 768×1024）
  ─────────────────────────────────────
  原文：用户要求：用图1的人物，穿图2的服装
  → 组装指令：英文标签（SDXL/Pony），共 1193 字
  → 请求已发送（超时 90 秒）
  ← 收到响应 9.0 秒　用量：输入 2516 / 输出 91 token
  ─────────────────────────────────────
  结果：1girl, ……
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

重试、参数降级、自动切换模型、格式异常等情况都会以 `⚠` 标出，并附带中文建议。

最终失败时，完整的请求信息会写入插件目录下的 `last_error.log`（每次覆盖，只保留最近一次），可以直接发给AI帮忙排查。

## 常见问题

| 现象                             | 原因                        | 解决                                 |
| ------------------------------ | ------------------------- | ---------------------------------- |
| 菜单里没有节点                        | 文件夹多套了一层，或加载出错            | 检查目录结构；查看启动日志中 `[CustomNodes]` 的行  |
| 没有找到 xxx 的 API Key             | json 未填写或填错位置             | 检查 `ai_prompt_keys.json`，改完重启      |
| HTTP 401 / 403                 | Key 错误、失效或服务未开通           | 重新复制 Key                           |
| HTTP 402                       | 余额不足                      | 到服务商官网充值                           |
| HTTP 404，提到 model              | 手填的模型名错误或已下线              | 点"获取模型列表"重选，或清空模型栏                 |
| SSL UNEXPECTED_EOF / timed out | 代理线路不稳定或未开代理              | 稍后重试；更换代理节点；在"代理地址"中填写本地端口         |
| xxx 不支持图像输入                    | 服务商没有视觉能力                 | 换用通义千问、Gemini 等，或在 json 中设置 vision |
| 多次返回中文                         | 模型不遵守英文要求                 | 换更强的模型，或降低创意度                      |
| 点运行结果不变                        | "每次运行"为固定                 | 改为随机                               |
| 自定义服务商不出现                      | 未重启 / base 为空 / JSON 格式错误 | 检查后重启                              |
| 改了文件夹名后找不到 Key                 | 改名时 ComfyUI 仍在运行          | 关闭 ComfyUI 再改名，然后重启                |

**费用大概多少？** 以 Gemini 3.8 Flash 为例，一次单图逆推约 1500 token，双图编辑指令约 2500 token，都在人民币一分钱左右。纯文字扩写更便宜。具体价格以各服务商官网为准。本插件不收取任何费用，API 费用由用户自行承担。

**会不会把我的 Key 传出去？** 不会。Key 只保存在本地 json 文件中，仅用于直接请求你选择的服务商。

## 开发：添加自己的节点

插件内置一个自动加载框架：**把 `.py` 文件放进 `nodes/` 目录，重启 ComfyUI 即可使用**，不需要修改任何其他文件。

**节点文件要求：**

- 文件名不以下划线开头（下划线开头的是公共模块，不会被当成节点加载）
- 文件末尾定义 `NODE_CLASS_MAPPINGS` 和 `NODE_DISPLAY_NAME_MAPPINGS`
- 菜单位置：`CATEGORY = "自定义/<功能大类>/<分组>"`

**快速开始：** 复制 `nodes/_template.py`，改名（如 `my_node.py`），按注释修改即可。

**复用公共能力：** `nodes/_shared.py` 提供了日志、AI 调用、Key 管理等功能：

```python
from _shared import Log, call_ai, load_key, clean_text, join_parts, img_to_b64

key = load_key("Gemini")
text, model, usage = call_ai("Gemini", "", key, "系统指令", "用户输入", 0.5)

log = Log()
log.head("我的节点")
log.add("结果：" + text)
log.flush()
```

| 函数 | 作用 |
|---|---|
| `Log` | 统一风格的流程日志 |
| `get_all_providers()` | 读取全部服务商配置 |
| `load_key(服务商)` | 获取 API Key |
| `call_ai(...)` | 调用 AI，自动处理各家格式差异和参数降级，支持多图 |
| `fetch_models(...)` | 获取模型列表 |
| `img_to_b64(tensor)` | ComfyUI 图像转 base64（自动限制 1024px） |
| `clean_text(s)` | 清洗 AI 返回的文本 |
| `advice(错误信息)` | 错误信息转中文建议 |
