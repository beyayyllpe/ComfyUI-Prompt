# ComfyUI-Prompt

给 ComfyUI 用的中文提示词工具集。用大模型把中文描述翻译或扩写成适合各种底模的提示词，支持看图逆推、多图融合、改图指令和视频提示词，另外附带一组 H3 视频节点。

零依赖：只用 Python 标准库和 ComfyUI 自带的库，不需要 `pip install`。

---

## 节点一览

| 节点 | 作用 |
|---|---|
| ✨ 提示词翻译（扩写/翻译） | 中文描述 → 底模对应格式的提示词，支持看图、多图融合、改图指令 |
| ✨ 提示词翻译（含CLIP编码） | 同上，直接输出条件，省一个文本编码节点 |
| 📝 多行提示词（逐条出图） | 一行一条提示词，一次运行依次出多张图 |
| 🎬 视频提示词（AI当导演） | 用大白话写想法，输出视频提示词 |
| H3 系列节点 | 海螺 H3 视频的多段输入、潜空间保存/读取、视频合并等 |
| 🌐 节点汉化（AI） | 把其他节点的界面翻译成中文 |

菜单位置：右键 → 添加节点 → **自定义**

## 安装

1. 进入 `ComfyUI/custom_nodes/` 目录
2. 二选一：
   - Git 克隆：`git clone https://github.com/beyayyllpe/ComfyUI-Prompt.git`
   - 手动下载：点 **Code → Download ZIP**，解压后把文件夹改名为 `ComfyUI-Prompt`
3. 确认结构是 `custom_nodes/ComfyUI-Prompt/__init__.py`，而不是多套了一层文件夹
4. 重启 ComfyUI

首次启动会自动生成两个文件：
- `ai_prompt_keys.json`：填写 API Key
- `ai_prompt_templates.json`：AI 指令模板，可以直接修改

---

## 配置 API Key

用记事本或 VS Code 打开 `ai_prompt_keys.json`，把 Key 填进对应服务商，用不到的留空，保存后重启 ComfyUI：

```json
{
  "DeepSeek": "sk-xxxxxxxx",
  "Gemini": "",
  "OpenAI": "",
  "Claude": ""
}
```

Key 的读取顺序：节点参数 → `ai_prompt_keys.json` → 系统环境变量。

> ⚠️ **不要把 Key 填在节点参数里。** ComfyUI 会把整个工作流写进出图的 PNG 元数据，分享图片就等于分享了你的 Key。

### 支持的服务商

| 服务商 | 网络 | 能否看图 |
|---|---|---|
| DeepSeek | 国内直连 | ✅ |
| 通义千问 | 国内直连 | ✅ |
| Gemini | 需要外网 | ✅ |
| OpenAI | 需要外网 | ✅ |
| Claude | 需要外网 | ✅ |
| 腾讯翻译 / 百度翻译 | 国内直连 | ❌ 只做机器翻译 |

同一家服务商里，不同型号的看图能力可能不同。接了图却选了不能看图的型号，节点会直接拦下并提示，不会浪费额度。

任何 OpenAI 兼容的接口（硅基流动、智谱、Kimi、OpenRouter 等）都可以在 JSON 里添加，添加后下拉框自动出现。

## 使用：提示词翻译

最常用的节点，主要参数如下：

| 参数 | 说明 |
|---|---|
| 文本 | 你的描述或编辑意图，可以写"图1""图2" |
| 目标格式 | 按你要用的底模选，见下表 |
| 扩写程度 | 不扩写 / 简洁 / 适中 / 详细 |
| 服务商、模型 | 模型留空则用推荐模型 |
| 每次运行 | 固定：内容没变就复用上次结果，不重复扣费；随机：每次重新生成 |

### 目标格式怎么选

| 选项 | 适用底模 |
|---|---|
| 中文 | Z-Image、Qwen-Image、可图、混元、Wan |
| 英文句子 | Krea 2、FLUX.2 |
| 英文标签 | SDXL、Pony、Illustrious |
| 编辑指令（英文 / 中文） | Qwen-Image-Edit、FLUX Kontext |
| 负面词（英文） | 仅 CFG > 1 时有效 |
| 不处理 | 原样输出，不调用 AI |

> ⚠️ SDXL 系列的文本编码器看不懂中文，用于 SDXL 时必须选"英文标签"。

### 扩写程度

四档控制的是细节挖得多深，不是砍掉内容。"不扩写"只翻译整理，不增加内容。

### 用图片

- **单图逆推**：接一张图到"图像1"，文本留空，选好目标格式。
- **多图融合**：接多张图，文本写"用图1的人物，穿图2的服装，放在图3的场景里"。最多接 10 张，接口会随连线自动增加。
- **编辑指令**：目标格式选"编辑指令"，文本写意图，例如"让图2的女孩穿上图1的衣服"。

### 标签格式的长度限制

SDXL 的文本编码器每 77 个 token 为一段，段与段之间互相看不见。标签写得太长，后面的词会失效，修饰语还可能和它修饰的词分到不同段。所以标签档约 50 个词，超出部分会被自动裁掉。

### 高级参数

点"显示高级输入"展开，可以设置：风格方向、开头/结尾固定文字（适合放 LoRA 触发词）、给 AI 的额外要求、临时自定义指令等。

## 使用：多行提示词

一行写一条提示词，一次运行依次出图，写几行出几张。

- 空行和 `#` 开头的行会被忽略
- 可以自动在每行加开头或结尾的固定文字（默认 `<sks>`）
- 中文角度简写会自动转成英文，例如 `右前 仰拍 特写` → `front-right quarter view high-angle shot close-up`
- 输出提示词列表、文件名列表和条数，文件名会带编号

最初为 Qwen-Image-Edit-2511 的多角度 LoRA 训练集制作设计。

---

## 使用：视频提示词

- **目标模型**：H3
- **五个拍摄开关**（分镜、运镜、光线、表情、声音）：默认都是"交给AI"，想固定某项时再拨开，拨了就是硬命令
- **五种模式**：文生视频、首帧、首尾帧、尾帧、参考素材，按接入的图片自动判断
- **稳定性提醒**：设置不合理时，中文说明里会直接给出数字，例如"15 秒切 10 个镜头，平均每镜 1.5 秒"

---

## 使用：H3 视频节点

| 节点 | 作用 |
|---|---|
| H3 多段输入 / H3 批量添加引导 | 组织多段视频的输入 |
| H3 潜空间前缀复制 / 保存 / 读取 | 在视频段之间传递潜空间 |
| H3 续接重叠帧修剪 | 续接时去掉重复的帧 |
| H3 音视频潜空间分离 | 把音频和视频的潜空间拆开 |
| H3 视频联合解码 | 解码生成的视频 |
| H3 视频合并 | 合并多段视频 |
| H3 释放内存 | 清理显存 |

具体参数请看节点上的悬浮说明。

---

## 使用：节点汉化

运行一次，它会扫描已安装的节点，用你配置的 AI 服务商把节点名称和参数翻译成中文，结果保存在 `translations/zh-CN/`。译文是普通文本文件，可以直接修改，刷新网页即可生效。

## 项目结构

```
ComfyUI-Prompt/
├── __init__.py                 入口：自动加载 nodes/ 下的所有节点
├── nodes/                      节点代码，一个文件一组节点
│   ├── _shared.py              公共工具（服务商、调用 AI、日志等）
│   ├── _template.py            新节点模板
│   └── ...                     其他节点文件
├── web/                        前端脚本
├── translations/zh-CN/         中文译文
├── ai_prompt_keys.json         API Key（自动生成，不上传）
├── ai_prompt_templates.json    AI 指令模板（自动生成，不上传）
└── docs/开发新节点.md          如何添加新节点
```
